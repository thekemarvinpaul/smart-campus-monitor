# 🖥 Smart Campus Network Monitoring System

A real-time network monitoring dashboard built using Python Dash to visualize and track the status of campus network devices, latency, and system performance

## Features

- Real-time device status monitoring (Online / Offline)
- Network latency visualization
- Interactive data tables and charts
- Clean dashboard UI for easy monitoring
- Scalable structure for campus-wide deployment

## Problem It Solves

Campus networks often lack a simple way to monitor device health and performance in real time.  
This system provides a centralized dashboard for quick network insights and decision-making.

## Tech Stack

- Python
- Dash (Plotly Dash)
- Plotly
- Pandas
- HTML components (Dash)
- Git & GitHub
